# БОТАНИКА — Авторская цветочная студия (г. Москва)

Веб-сайт и интерактивная интернет-витрина локальной авторской цветочной студии «БОТАНИКА» (ул. Малая Бронная, 18, Патриаршие пруды).

## Стек технологий

- **React 18** + **TypeScript**
- **Vite**
- **Tailwind CSS** (с кастомной дизайн-системой в стиле Aesop & Kinfolk)
- **Lucide Icons**
- **Локальная база данных на localStorage** с реактивными обновлениями в реальном времени

## Концепция дизайна (Anti-Slop / Editorial Modern Boutique)

- Журнальная типографика: заголовочная антиква **Cormorant Garamond** + гротеск **Manrope**
- Цветовая палитра:
  - Основной фон: алебастровый / тёплый молочный (`#F9F8F6`)
  - Поверхности карточек: мягкий бежево-серый (`#F0EDE8`)
  - Основной текст: графит (`#1C1B1A`)
  - Акцент: приглушенный оливково-хвойный (`#2E3D32`) и терракотовый (`#B85D43`)
  - Тонкие 1px разделители (`#E2DDD5`)
- Никаких кислотных или фиолетовых неоновых градиентов, тяжелых теней и клише

## Основной функционал

### Для покупателя:
1. **Асимметричный Hero-экран**: экспресс-доставка за 90 минут, фотоотчёт букета перед отправкой в мессенджер, аквапак с водой и кризал в комплекте.
2. **Сезонный каталог букетов**: фильтрация по категориям («Все», «Авторские», «Монобукеты», «Сухоцветы»), сортировка по цене.
3. **Боковое окно букета (Product Drawer)**: выбор размера (S / M / L) с динамическим расчетом стоимости, диаметра и количества стеблей, рецепт состава и советы по уходу.
4. **Сборка по бюджету**: интерактивный подбор букета шеф-флористом по сумме, настроению палитры и поводу.
5. **Выезжающая корзина (Cart Drawer)**:
   - Изменение количества и удаление позиций
   - Бесплатная открытка с персональным текстом поздравления
   - Оформление заказа (доставка курьером по Москве или самовывоз из студии со скидкой 10%)
   - Экран подтверждения с присвоением номера заказа `#BOT-XXXX`

### Закрытая панель флориста (/admin):
- **Доступ**: демо-доступ по логину `admin` и паролю `florist2026`
- **Метрики в реальном времени**: новые заказы, выручка за день, средний чек, общее количество
- **Журнал заказов**: синхронизация в реальном времени (новые заказы покупателей мгновенно появляются в панели со статусом «Новый»)
- **Смена статусов**: «Новый» → «Собирается» → «Передан курьеру» → «Выполнен» → «Отменен»
- Предзаполненные тестовые заказы и возможность сброса данных

## Запуск проекта локально

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Сборка production
npm run build
```
